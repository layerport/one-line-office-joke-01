## The joke

> We named our meeting rooms after virtues we don't practice — the Transparency room has no windows.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line to
`/output/entry.txt`. The output is deterministic: the same bytes on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
